# Sicherheit

Kleinkontor verarbeitet Geschäfts- und Kundendaten. Wenn du eine Sicherheitslücke findest, melde sie bitte **nicht** öffentlich als Issue, sondern vertraulich über die Funktion „Report a vulnerability“ (Security Advisories) dieses Repositorys.

Bitte beschreibe, wie sich das Problem nachvollziehen lässt und welche Version betroffen ist. Wir melden uns so bald wie möglich.

Hinweise zum sicheren Betrieb stehen in der README im Abschnitt „Sicher betreiben“.
